**Container image** is an effectively immutable version of an application that includes its libraries

**Stable development target** and **Ease of testing and deployment** are two advantages of using containers

**Open Container Initiative** organization directly governs the standards for containerization

An application in an OCI container runs on any OCI-compliant container engine is **True**

**Container instance** is the running version of a container image that includes references to networking, storage, and other runtime necessities

A virtual machine most often has a smaller footprint compared to a container is **False**

**Container engine** provides machine-level functionality for running containerized applications

Statement about **Kubernetes is an orchestration service that simplifies the deployment, management, and scaling of containerized applications**

You can gradually roll updates out to your application's containers while checking their status is **True**

Kubernetes enables inter-service communication by assigning a single DNS entry to each set of containers is **True**

Features does Red Hat OpenShift Container Platform (RHOCP) offer to extend Kubernetes capabilities are **Unified UI that provides unified tools and an integrated UI to manage the different capabilities** and **Developer workflow that integrates a built-in container registry, Continuous Integration/Continuous Delivery (CI/CD) pipelines, and a Source-to-Image (S2I) tool**.

Statements are true regarding RHOCP are **Integrates a built-in container registry to build artifacts from source repositories to container images** and **RHOCP simplifies routing and load balancing.**
