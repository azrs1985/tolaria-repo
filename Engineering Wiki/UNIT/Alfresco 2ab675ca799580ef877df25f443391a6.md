# Alfresco All-in-One Installe

**Cài đặt Alfresco Community Edition hoàn chỉnh chỉ với 1 lệnh!**

Bao gồm: **Alfresco Repository, Share, Content App, Solr, Transform Service, ActiveMQ, Nginx (HTTP), Backup tự động, REST API Explorer**.

> Không HTTPS – phù hợp dev, test, local.
> 
> 
> Muốn HTTPS? Chỉ cần sửa `.env` → chạy lại.
> 

---

## Tính năng

| Tính năng | Mô tả |
| --- | --- |
| **1-click install** | `sudo ./install.sh` |
| **Không hardcode** | Tất cả cấu hình trong `.env` |
| **User hiện hành** | Tự động dùng user chạy script |
| **Backup tự động** | Hàng ngày 2:00 AM → `/appvol/backups` |
| **REST API Explorer** | `http://localhost/api-explorer` |
| **Tự động restart** | Service crash → systemd tự khởi động |
| **Kiểm tra hệ thống** | `sudo ./check_alfresco.sh` |

## Yêu cầu hệ thống

- **OS**: Ubuntu 20.04 / 22.04 / 24.04
- **RAM**: ≥ 8GB (khuyến nghị 16GB)
- **Disk**: ≥ 50GB (cho content + backup)
- **Internet**: Cần tải package & resources
- **Quyền**: `sudo`

## Hướng dẫn cài đặt (3 bước)

### Bước 1: Tạo thư mục & copy file

```bash
mkdir alfresco-installer && cd alfresco-installer
```

**→ Copy toàn bộ 13 file từ hướng dẫn vào đây**

### Bước 2: Chạy cài đặt

```bash
chmod +x *.sh install.sh
sudo ./install.sh
```

> Thời gian: ~10–15 phút (tùy mạng)
> 

---

### Bước 3: Kiểm tra hệ thống

```bash
sudo ./check_alfresco.sh
```

### Kết quả mẫu (khi OK):

```bash
[OK] PostgreSQL
[OK] Tomcat
[OK] Solr ($SOLR_PORT)
[OK] Content App<a href="<http://localhost>" target="_blank" rel="noopener noreferrer nofollow"></a>
[OK] Backup tồn tại: /appvol/backups/2025-11-14
[OK] Cron backup đã setup
```

> *Nếu có [FAIL], script sẽ báo rõ → dễ fix.*

## Cấu hình trong .env

| Biến | Mô tả | Ví dụ |
| --- | --- | --- |
| `APPVOL` | Thư mục chính | `/appvol` |
| `DB_PASS` | Mật khẩu DB | `your-strong-pass` |
| `DOMAIN` | Domain/IP | `localhost` hoặc `192.168.1.100` |
| `BACKUP_CRON` | Thời gian backup | `0 2 * * *` (2:00 AM) |

> *Chỉ cần sửa .env → chạy lại [install.sh](http://install.sh/) → cập nhật tự động!*
> 

## Backup & Restore

### Backup tự động

- Lưu tại: `/appvol/backups/YYYY-MM-DD/`
- Giữ 7 ngày gần nhất
- Bao gồm: DB, content store, Solr index, config

### Chạy thủ công

```bash
sudo /usr/local/bin/backup_alfresco.sh
```

Restore (ví dụ)

```bash
#DB
psql -U alfresco -d alfresco < /appvol/backups/2025-11-14/alfresco-db-*.sql

#Content
sudo tar xzf /appvol/backups/2025-11-14/alf_data-*.tar.gz -C /appvol
```

### Nâng cấp lên HTTPS (sau này)

Chỉ cần sửa `.env`:

```bash
ALF_PROTOCOL=https
ALF_PORT_HTTP=443
DOMAIN=your-domain.com
SSL_EMAIL=admin@your-domain.com
```

→ Chạy lại:

```bash
sudo ./install.sh
```

→ Tự động: Nginx SSL + Let's Encrypt

### Gỡ cài đặt (nếu cần)

```bash
sudo systemctl stop tomcat solr activemq transform nginx postgresql
sudo rm -rf /appvol /var/www/alfresco-content-app
sudo rm /etc/systemd/system/{tomcat,solr,activemq,transform}.service
sudo systemctl daemon-reload
```
