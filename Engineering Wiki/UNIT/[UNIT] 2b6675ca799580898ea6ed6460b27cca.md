Để **tự động giới hạn log file tối đa 100MB** trên Ubuntu, bạn nên cấu hình **logrotate**. Đây là công cụ mặc định ca hệ thống để xoay vòng (rotate), nén, và xóa log theo dung lượng hoặc thời gian.

---

## 🛠 Các bước cấu hình logrotate

### 1. Kiểm tra logrotate đã cài chưa

```bash
dpkg -l | grep logrotate

```

Nếu chưa có, cài bằng:

```bash
sudo apt install logrotate

```

---

### 2. Tạo file cấu hình riêng cho log

Ví dụ bạn muốn giới hạn `/var/log/myapp.log`:

```bash
sudo nano /etc/logrotate.d/myapp

```

Thêm nội dung:

```
/var/log/myapp.log {
    size 100M
    rotate 5
    compress
    missingok
    notifempty
    create 0640 root adm
}

```

---

### 3. Giải thích các tham số

- `size 100M` → khi log đạt 100MB thì xoay vòng.
- `rotate 5` → giữ tối đa 5 file log cũ (myapp.log.1 … myapp.log.5).
- `compress` → nén log cũ bằng gzip để tiết kiệm dung lượng.
- `missingok` → nếu file log không tồn tại thì bỏ qua, không báo lỗi.
- `notifempty` → không xoay nếu file rỗng.
- `create 0640 root adm` → tạo file mới với quyền và owner cụ thể.

---

### 4. Kiểm tra cấu hình

Chạy thử:

```bash
sudo logrotate -d /etc/logrotate.conf

```

(`-d` = debug, không thực thi thật).

Nếu ổn, chạy:

```bash
sudo logrotate /etc/logrotate.conf

```

---

### 5. Tự động hóa

- Logrotate thường được cron gọi hàng ngày (`/etc/cron.daily/logrotate`).
- Bạn chỉ cần cấu hình đúng trong `/etc/logrotate.d/` là hệ thống sẽ tự động xoay vòng.

---

✅ Với cách này, bạn không cần truncate thủ công nữa. Log sẽ **tự động xoay vòng khi đạt 100MB**, giữ lại số bản cũ theo cấu hình.

Bạn có muốn mình viết thêm một **ví dụ cấu hình cho toàn bộ `/var/log/*.log`** để áp dụng chung, thay vì chỉ cho một file riêng lẻ không?
